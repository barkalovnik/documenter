# ClassDocumenter

Класс создан как вторая лабораторная работа по курсу "Инжиниринг программного обеспечения" на третьем курсе НГТУ НЭТИ

При вводе имени класса создает документ в формате pdf или html c описанием структуры объекта, а также тех классов, на которые в объекте имеются ссылки или массивы ссылок. Обработка производится рекурсивно, с исключением повторной обработки уже просмотренных классов.
